# 🎬 CineScope

A Blazor WebAssembly learning project that integrates with [The Movie Database (TMDB) API](https://www.themoviedb.org/) to display movie information in a modern, responsive web application.

---

## 📖 About

CineScope is a hands-on learning project built to explore:
- Consuming a real-world REST API (TMDB) in a Blazor app
- Building responsive UI components with Bootstrap 5
- Structuring a Blazor WebAssembly application with layouts, pages and reusable components

---

## ✨ Features

> Features are added progressively as the project develops.

- [ ] Browse movies **Now Playing** in theatres
- [ ] Browse **Popular** movies on TMDB
- [ ] **Search** for movies by title
- [ ] Save a list of **Favourite** movies

---

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| C# / .NET 8 | Core language & runtime |
| Blazor WebAssembly | SPA framework |
| Bootstrap 5 | Responsive UI & layout |
| Bootstrap Icons | Icon library |
| JavaScript | Browser interop |
| HTML5 / CSS3 | Markup & styling |
| [TMDB API](https://www.themoviedb.org/documentation/api) | Movie data source |
